# AppFinanzas · demo UX

Prototipo público y temporal para revisar la experiencia de uso en móvil y escritorio.

- Usa exclusivamente datos sintéticos en memoria.
- No tiene autenticación, persistencia, conexión a Supabase ni datos financieros reales.
- El estado de la demo se reinicia al recargar y no se comparte entre dispositivos.
- GitHub Pages publica este sitio de forma pública; no introduzcas aquí información privada.

La aplicación definitiva y la fuente de verdad del proyecto siguen en el repositorio privado `AppFinanzas`.
